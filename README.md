🎨 Excalidraw Clone

A full-stack drawing application inspired by Excalidraw, built with HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

✨ Features
✏️ Draw and create diagrams
🖱️ Interactive canvas
🎨 Drawing and styling tools
💾 Save drawings to the database
📂 Load saved drawings
🔗 REST API for frontend-backend communication
🗄️ MongoDB for data persistence
🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB

⚙️ Run Locally
git clone <your-repository-url>
cd <project-folder>

cd backend
npm install
npm start

Then open the frontend in your browser.

Create a .env file in the backend with your MongoDB connection string.
